# 提词器 1.0.0

仅提供二进制安装包，不包含项目源码。

[前往 Release 下载](https://github.com/redfoxpum/prompter/releases/tag/v1.0.0)

## curl 下载

Mac M 系列：
```sh
curl -fL -o prompter-mac-arm64.dmg https://github.com/redfoxpum/prompter/releases/download/v1.0.0/prompter-1.0.0-mac-arm64.dmg
```

Mac Intel：
```sh
curl -fL -o prompter-mac-x64.dmg https://github.com/redfoxpum/prompter/releases/download/v1.0.0/prompter-1.0.0-mac-x64.dmg
```

Windows x64 安装版：
```sh
curl.exe -fL -o prompter-setup.exe https://github.com/redfoxpum/prompter/releases/download/v1.0.0/prompter-1.0.0-windows-x64-setup.exe
```

Windows x64 绿色版：
```sh
curl.exe -fL -o prompter-portable.zip https://github.com/redfoxpum/prompter/releases/download/v1.0.0/prompter-1.0.0-windows-x64-portable.zip
```

Mac 打开 DMG 后将“提词器”拖入应用程序；Windows 绿色版解压整个 ZIP 后运行“提词器.exe”。启动后填写发送端提供的配对凭证即可连接。
